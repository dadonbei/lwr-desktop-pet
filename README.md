# lwr桌宠

ChatGPT Work 自定义桌宠项目，使用真人照片质感的最终 v2 动作图集。常态保留原照片中的手势：一只手放在脑后，另一只手扶腰/胯部。

仓库名：`lwr桌宠`（私有仓库）

## 文件

- `lwr-pet-v2.png`：Pets 安装用原始 v2 图集，1536×2288 RGBA PNG，8 列×11 行，每格 192×208。请勿用 GIF 预览替代，也不要对安装图集进行缩放、重绘或二次压缩。
- `ABOUT.md`：介绍、GIF 预览与 AI 安装提示词。
- `安装教程.md`：手动安装说明。
- `all-actions.gif` 与其他 GIF：仅供预览。

原始 HEIC 照片和抠图参考没有放进此仓库；需要安装时只使用 `lwr-pet-v2.png`。

## 快速安装

确保你的 GitHub 账号有权访问此私有仓库，然后按 [`安装教程.md`](安装教程.md) 操作。
